# HR Data Cleaning & Exploratory Data Analysis (EDA)

This project focuses on cleaning and analyzing a large HR dataset using Python libraries such as NumPy, Pandas, Matplotlib, and Seaborn.

## Objectives
- Clean and preprocess messy HR data
- Perform exploratory data analysis (EDA)
- Visualize key trends in attrition, salary, and job roles

## Tools Used
- Python
- Jupyter Notebook
- Pandas, NumPy
- Matplotlib, Seaborn

## Files
- `HR_Data_Cleaning.ipynb`: Notebook with cleaning and EDA steps
- `dirty_hr_large.csv`: Raw dataset (if available)

## How to Run
1. Download or Clone the repository
2. Open `HR_Data_Cleaning.ipynb` in Jupyter Notebook
3. Run each cell to follow the data cleaning and analysis process
